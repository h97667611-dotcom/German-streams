# Universal Scraper\n\nReusable generic fetch, metadata extraction, configurable search selectors, and direct HLS/MP4 detection are implemented in `core/universal-scraper.js`. Sources must be explicitly marked `authorized: true`; current registry keeps sources disabled pending official API/permission review. This does not bypass login, DRM, paywalls, CAPTCHA, or access controls.\n\nRequires a runtime with fetch, URL, and DOMParser. The Nuvio provider is not wired to this engine yet; verify the Nuvio plugin API/runtime and implement source-specific adapters before returning streams.\n
