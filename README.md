# German Streams / Media Directory

Curated German-language media directory. This is not a stream resolver or scraper.

## Install page
Open the [German Streams install page](https://h97667611-dotcom.github.io/German-streams/install.html). It offers the Nuvio account dashboard and a one-tap copy of the manifest URL. A Nuvio-specific automatic install deep link is not documented/verified, so the button does not pretend to install directly into the app.

Manifest: `https://raw.githubusercontent.com/h97667611-dotcom/German-streams/main/manifest.json`

## Scope
Official/public-service and educational sources are listed for discovery. Third-party sites are reference links only; legality, safety, current status and licensing are not verified. No copyrighted stream extraction, scraping, downloading or playback integration is implemented. The provider remains disabled and returns no stream URLs.
