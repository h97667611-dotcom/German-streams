# German Streams / Media Directory

This repository contains a curated directory of German-language media sources and references. It is **not** a stream resolver or scraper.

## Nuvio manifest
The repository manifest is an object with a `scrapers` array, as expected by current Nuvio repositories. The single provider is intentionally disabled and returns no stream URLs.

## Scope
- Official/public-service and educational sources are listed for discovery.
- Third-party streaming, download, and index sites are reference links only. Their legality, safety, current status, and licensing are not verified.
- No copyrighted stream extraction, scraping, downloading, or playback integration is implemented.
- See [`catalog/german-sources.json`](catalog/german-sources.json) for the expanded directory.

## Install
Use this raw manifest URL in Settings → Content & Discovery → Plugins:
`https://raw.githubusercontent.com/h97667611-dotcom/German-streams/main/manifest.json`

The repository is a directory and currently returns no streams. Use official sources and confirm content rights in your region.
